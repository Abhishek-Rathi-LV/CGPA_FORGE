# CGPAForge — GitHub Ready

Standalone IPU CGPA calculator.

## Deploy
Upload `index.html` to a static host, or use this repository with a static/Pages deployment.

## Included
- 8 blank subject rows by default
- Automatic Marks %
- Automatic Credit %
- SGPA calculation
- IPU grade scale
- Target CGPA / What-if / history features from the app
- Improved multi-page PDF report
- PDF includes per-subject Marks %, Credit %, grade, grade point and quality points
- PDF includes summary metrics, marks analysis, formula, IPU grade scale, interpretation notes and creator link

PDF export uses the client-side jsPDF library loaded by the page.
